Overcoming High-Dimensional Collapse and Voronoi Overfitting in K-Means: Spectral Intrinsic-Dimension Minimum Description Length (SID-KMeans)

Andrew Rober Fouad Samy · BytesGlue (Dubai, United Arab Emirates) · andrew.rober@bytesglue.com
📄 Download Full Paper (PDF) 💻 GitHub Code & Benchmarks 🤗 HuggingFace Repository 🔗 LinkedIn

Abstract

Introduces Spectral Intrinsic-Dimension Minimum Description Length (SID-KMeans), a zero-hyperparameter automatic cluster-count (K*) selection method combining exact marginal LogSumExp mixture likelihood (eliminating hard Voronoi truncation bias), Gavish-Donoho Marchenko-Pastur random-matrix bulk denoising, and Satterthwaite-Welch effective degrees of freedom. Achieves 100% within-1 K* accuracy across 60 real 768D and 1024D Transformer embedding corpora on NVIDIA GB10 with exact scale, translation, and orthogonal rotation invariance.
